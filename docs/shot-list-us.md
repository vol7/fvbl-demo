# US shot list

Ten clips from the Ohio app for the US cut. Times are seconds into each clip.
Each action runs until the next one starts, timed to Victoria's takes
(`video/public/audio/vo/us/`). The voice column is what plays over it.

## Setup

- App: `http://localhost:5173/us` (the hub). It opens each surface in its own
  window.
- Desktop windows at **1440×900**, the phone at **390×844**.
- **Reset session** in the hub between takes. **Force state** jumps to a beat.
- Save each clip to `video/public/clips/us/<file>`. The cut plays it in place
  of the Ontario file.
- Check in Studio (`Demo-US`) after each clip: the voice should land on each
  action.
